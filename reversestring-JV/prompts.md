# Prompts

## PROMPT #1

You are an expert frontend developer. Your task is to create a simple web application
that reverses a string of text input by the user.

### Functional Requirements

- The user types any string in a text input field, example: AI4Devs
- The app displays the reversed string on button click: sveD4IA
- The reverse string logic must be in script.js file
- The UI structure must be in index.html file

### Technical Constraints

- Use standard HTML, CSS, and JavaScript (no frameworks, no external libraries)
- The project must only use the previously mentioned files:
  - index.htm
  - script.js
- Do not create additional files

### Expected Behavior

1. User opens index.html in a browser
2. User types a string in the input field
3. When the user clicks on "Reverse" button, the reversed string is displayed (as shown in the attached image)
4. Consider the string may contain empty string, spaces, special characters, numbers
5. Use comments to explain code logic

### Deliverables

1. Final content of index.html (using the following base)
2. Final content of script.js
